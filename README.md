# Aivora Labs — starter website

## Run locally
1. Extract the ZIP (if using the ZIP).
2. Open the `AivoraLabs` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension if you already have it.
4. Test mobile layout, navigation, FAQ buttons, and the contact form's demo message.

## Important before sharing publicly
- The BrightPath FAQ is fictional demo content.
- The contact form does NOT send or store enquiries. It only displays a demo message.
- Replace placeholder contact details/links before adding any real contact links.
- Do not claim the sample assistant uses AI; it is a prewritten guided demo.
- Do not add invented testimonials, client logos, or performance results.
